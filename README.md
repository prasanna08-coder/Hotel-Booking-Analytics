# Hotel Booking Analytics

## Project Overview

This project analyzes hotel booking data using Python and Pandas to identify occupancy patterns, booking trends, room preferences, and revenue performance.

## Tools Used

- Python
- Pandas
- Jupyter Notebook

## Analysis Performed

- Data cleaning and handling missing values
- Exploratory data analysis (EDA)
- City-wise and room-wise occupancy analysis
- Weekday vs weekend occupancy comparison
- Booking platform analysis
- Revenue analysis

## Key Business Insights

- Weekend occupancy (72.34%) is higher than weekday occupancy (50.88%).
- Delhi has the highest occupancy (61.51%), while Bangalore has the lowest (56.33%).
- Mumbai generates the highest realized revenue (668.57 million in dataset currency units).
- Presidential rooms have the highest average occupancy (59.28%).
- The 'others' booking platform category records the highest number of bookings.

## Business Recommendations

- Introduce weekday promotional offers to improve occupancy.
- Use targeted marketing campaigns in lower-occupancy cities.
- Optimize room promotions based on occupancy trends.
- Evaluate booking platform performance to improve marketing strategies.
